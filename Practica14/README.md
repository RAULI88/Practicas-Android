# Practica14 — Práctica 14 GPS y Mapas

Desarrollo Móvil Nativo · Kotlin + Jetpack Compose

Permisos de ubicación, coordenadas con FusedLocationProviderClient, mapa interactivo OpenStreetMap (OSMdroid) con marcador, ícono GPS rojo y marcadores guardados en Room con pulsación larga.

- Mapa: OpenStreetMap con OSMdroid (no requiere API key ni cuenta de facturación).
- Mantén presionado el mapa para guardar un marcador (Room). El botón de lista muestra/borra los guardados.
- En el emulador: Extended Controls > Location para simular la posición.
