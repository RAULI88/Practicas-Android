# Practica11 — Práctica 11 Archivos

Desarrollo Móvil Nativo · Kotlin + Jetpack Compose

Lectura/escritura de archivos de texto en memoria interna y externa/SDCard (File, FileOutputStream, FileInputStream) con permisos en tiempo de ejecución, más el mini reproductor MP3 de la práctica (con botón Detener).

- Pestaña **Archivos**: escribe, agrega, lee y elimina archivos `.txt` en memoria interna, almacenamiento externo o SDCard física (si el emulador/teléfono tiene una).
- Pestaña **Reproductor**: abre un MP3 con el explorador (GetContent) y lo reproduce con MediaPlayer. Reto: botón Detener (pause + seekTo(0)).
